# Agent rules

Rules every agent follows in this repository. The README describes the project.

## Review and merge

Before you open, review or merge a pull request here, follow the `team-process` plugin's
`review-and-merge` skill. It holds the rule and its reasons (MILLIT-826, MILLIT-989). Without the
plugin, read it at
https://github.com/MI-Avionics/claude-skills/blob/master/plugins/team-process/skills/review-and-merge/SKILL.md

Only in this repository:

- The `pipeline-review` bot does not review this repository. Add Devin or Reece as a reviewer.
